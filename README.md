# homebrew-skel

Homebrew tap for [skel](https://github.com/mark-mcdermott/skel) — app scaffolding from an indented tree.

## Install

```bash
brew tap mark-mcdermott/skel
brew install skel
```

## Maintenance

The formula is updated automatically by `make release` in the [skel](https://github.com/mark-mcdermott/skel) repo — don't edit `Formula/skel.rb` directly.
